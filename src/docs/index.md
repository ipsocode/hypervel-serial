# hypervel-serial documentation

Read the pages in this order:

1. [Getting started](getting-started.md): install the package, describe a device's commands and protocol, and send the first command.
2. [Configuration](configuration.md): connections, transports and their line settings, timing and retries, and the optional settings.
3. [Protocols](protocols.md): how a request becomes bytes and a reply becomes a result, with framing, encodings, checksums and headers.
4. [Transactions](transactions.md): sending requests, results and failures, holding the device for a sequence of requests, reservations, events and logging.
5. [Testing](testing.md): faking connections, simulating a device, and testing a protocol against scripted bytes.
